ГАЛЬКИНО — ОБНОВЛЁННЫЙ САЙТ

Загрузите файлы из этого архива в корень репозитория GitHub Pages.
index.html — это ВАША текущая карта, в которую добавлена только навигация; координаты, анимация, мобильный режим не менялись.
Существующие изображения (village.png, village_foreground.png, timofey_alive.png, timofey_closed.png, marfa_alive.png, marfa_closed.png, prokhor_alive.png, prokhor_closed.png) ОСТАЮТСЯ на GitHub: их нет в архиве.

СТРАНИЦЫ И ИСТОРИИ
О деревне — about.html; жители — residents.html; как это работает — how.html; галерея — gallery.html; контакты — contacts.html; где купить — buy.html.
В stories.json указывайте реальные имена файлов историй. Пока указаны предположительные timofey.html и vasilisa.html — проверьте их. Остальные жители отображаются без несуществующих ссылок.

ПОРТРЕТЫ
Первые три жителя используют существующие *_alive.png рядом с index.html. Остальные ожидают images/residents/ID.png, например images/residents/anfisa.png. Если изображений нет, страница скрывает пустую картинку.

ГАЛЕРЕЯ
Добавьте изображения к историям в репозиторий, а их адреса и подписи — в gallery.json.
Пример: [{"file":"images/stories/timofey-1.png","title":"Тимофей у сада"}]
Пока JSON пустой: сами изображения рассказов не были приложены к этому сообщению, поэтому не добавлены фиктивные файлы.

ВАЖНО: GitHub Pages публичен — даже страницы для тестов не закрыты паролем.
JSON-файлы загружаются через HTTP(S), не открывайте html двойным щелчком с диска для проверки ссылок.
